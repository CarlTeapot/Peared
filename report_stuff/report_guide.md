## 2. Description of Report Sections

### 1) Title Page

See Appendix 1.

### 2) Abstract

The abstract provides a concise summary of the report. It should highlight the core idea of the project, relevance of the topic, objectives, and key results. The abstract must be written in both Georgian and English. The recommended length is 300–500 words.

### 3) Acknowledgments (Optional)

The acknowledgment page is optional and does not constitute a mandatory section of the report. Project member(s) may dedicate this page to individuals who contributed to the preparation and/or execution of the project (e.g., faculty members, project supervisor, peers, employers, etc.).

### 4) Table of Contents

The table of contents must present a detailed and sequential overview of all chapters and subchapters of the report, along with their respective page numbers.

### 5) List of Tables, Figures, Formulas, and Images

Every table, figure, formula, image, or other illustrative material used in the report must be titled and numbered (e.g., Figure 1. Home Page of the Application). The list must reflect the title and number of every table, figure, and image used in the report, along with their respective page numbers.

### 6) Introduction

The purpose of this section is to provide the reader with a general overview of the project. It should outline:

* The selection process of the project idea/topic;
* The motivation behind the student’s or group's interest in the specific project (topic);
* Problem identification;
* Relevance and significance of the project;
* Project objectives;
* Scope of the project;

2

* Methods and approaches used to execute the project;
* Potential users/domain of implementation;
* Possible limitations.

### 7) Main Body

#### 7.1) Domain Research Related to the Project Topic

The objective of this section is to provide readers with background information they may not already possess, but which is essential for understanding the project’s goal, relevance, and theoretical and practical value. This section should cover domain research related to the project topic:

* Existing technologies and market state in the domain;
* Challenges within the field;
* Future prospects and development opportunities.

Additionally, this section should define the nature of the project:

* The project presents a new, innovative idea in a specific domain; or
* The project offers an innovative solution to an existing challenge in a specific domain; or
* The project provides a method for optimizing an existing process within a specific domain.

Following the domain research and project nature, this section should cover:

* Technical specifications / requirements of the project;
* Hardware/software tools required for execution (if applicable);
* Need/relevance of the project;
* Potential commercialization of the project.

#### 7.2) Technical Aspects of the Project

This section must detail every stage of working on the technical specifications along with the technical characteristics of the project:

* User interface / Visual design;
* Functionality;
* Architecture;
* Software components;
* Hardware components;

3

* System design / infrastructure;
* Algorithms used;
* Software, technical, or other issues encountered during project development and their solutions;
* Implementation, etc.

Furthermore, this section must justify why the selected methods/approaches are optimal for executing the technical task.

#### 7.3) Results and Evaluation

Depending on the specific nature of the project, this section should detail:

* The final deliverable (e.g., completed website, application, etc.); and/or
* Data processing and conclusions derived from the project results.

Additionally, this section must assess the extent to which the student/team achieved the project goal and fulfilled the technical requirements.

**Note: In the case of a group project, the specific contribution of each team member must be clearly outlined. The subchapter containing this information must be included in the main body of the report.*

### 8) Conclusion

This section provides a summary of the entire project and should outline:

* Core aspects of the project;
* Results achieved;
* Knowledge/experience gained during the execution of the project;
* Future plans regarding the project, etc.

### 9) References

The list of references and in-text citations must strictly follow a single chosen citation style. Recommended styles are IEEE, ACM, or APA.

**Note: Using others' ideas, statistical data, or research without proper citation constitutes plagiarism.*

### 10) Appendices

In addition to standard appendices (if any), this section must include the project source code or provide a link to the corresponding codebase.

## 3. Text Formatting Requirements

1. Paper size – A4.
2. Font – Sylfaen.
3. Font size – 12.
4. Line spacing – 1.5.
5. Margins – 1” on all sides.
6. Alignment – Justified text (aligned to both left and right margins).
7. Report length – Recommended length is no more than 40 pages.
8. Page numbering:
* Title page – Unnumbered.
* Abstract, Acknowledgments, Table of Contents, List of Tables/Figures – Numbered with Roman numerals, starting from ii.
* Starting from the Introduction, all pages are numbered with Arabic numerals, starting from 1.
* Page numbers must be placed at the bottom right corner of the page.


9. The report must be written in Georgian or English.

**Note: If the language quality of the report is so poor that it hinders comprehension, it will not be accepted.*
